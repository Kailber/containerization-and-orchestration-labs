# Кебабернетес — бизнес-контекст

Документ для всех, кто пишет release notes фронтенда: что за продукт, кто читает заметки и как технические изменения влияют на клиентов.

## Продукт

Кебабернетес — сервис доставки еды из ресторанов. Команда фронтенда (8 человек) отвечает за веб-приложение для клиентов: от выбора ресторана до получения заказа. Новая версия выкатывается в прод каждое утро.

## Кто читает release notes

- **Менеджер продукта** — что изменилось для клиентов, может ли это повлиять на метрики, нужно ли предупредить поддержку или маркетинг.
- **Разработчики и QA** — что вошло в релиз и где искать изменения, если что-то сломалось.

## Ключевые метрики продукта

- Конверсия из корзины в оплаченный заказ.
- Доля отменённых заказов.
- Число обращений в поддержку («где мой заказ», «не прошла оплата»).
- Доля повторных заказов.

## Карта модулей

| Путь в репозитории | Что это для клиента | Почему важно бизнесу |
|---|---|---|
| `src/features/catalog/` | Список ресторанов, поиск, меню | Первое, что видит клиент; влияет на выбор ресторана |
| `src/features/cart/` | Корзина | Ошибки здесь — брошенные корзины |
| `src/features/checkout/` | Оформление заказа и оплата (карта, СБП, наличные курьеру) | Напрямую влияет на выручку; самое чувствительное место |
| `src/features/tracking/` | Отслеживание заказа, курьер на карте | Меньше обращений «где мой заказ» |
| `src/features/profile/` | Профиль, адреса, история заказов, «Повторить заказ» | Повторные заказы |
| `src/features/promo/` | Промокоды и акции | Маркетинг; ошибка может дать лишнюю скидку |
| `src/api/` | Клиент API бэкенда | Изменения могут затронуть всё приложение |
| `src/shared/` | Общие компоненты интерфейса | Изменения видны сразу на многих экранах |
| `package.json`, конфиги, `.github/` | Зависимости, сборка, CI | Клиенту не видно; важно только при уязвимостях или влиянии на скорость загрузки |

## Словарь

- **СБП** — Система быстрых платежей, оплата по QR-коду или через приложение банка.
- **Слот доставки** — выбранный клиентом интервал времени доставки.
- **«Повторить заказ»** — кнопка в истории заказов, собирает корзину из прошлого заказа.
- **Горячие предложения** — блок акций на главной странице.
- **Минимальная сумма заказа** — у каждого ресторана своя; без неё нельзя перейти к оплате.
